# 탤2짱 CLIP STUDIO

아이폰 Safari에서 사진·영상을 선택해 20초 세로 MP4를 만드는 모바일 웹앱입니다.

## 원본 MVP 분석

| 기능 | 첨부 원본 | 현재 코드 |
|---|---|---|
| 최대 18개 업로드 | 구현 | 용량 검사·업로드 진행률 추가 |
| HEIC/HEIF·MOV | 변환 경로 존재, 실행 검증 없음 | HEIF 디코더·HEVC MOV 통합 테스트 추가 |
| 자동 장면 선정 | 앞 10개만 사용 | 18개 모두 분석해 품질 상위 최대 10개 선정 후 원본 순서 배치 |
| 영상 하이라이트 | 중앙 구간 | 5개 구간의 선명도·노출·프레임 변화량 평가 |
| 사진 확대 | 구현 | 유지 |
| 장면 전환 | 단순 컷 | 짧은 페이드 아웃·인 |
| 한국어 자막 | 제작 전 입력 | 기본 문구 및 장면별 수정·재제작 |
| MP4 미리보기·다운로드 | 구현 | Safari Range 요청 확인 테스트 추가 |
| 1080×1920 | 선택 사항 | 기본 선택, 480프레임·24fps·20초 |
| 작업 관리 | 무제한 스레드·메모리 상태 | 렌더 1개씩, 대기열 제한, 파일 상태 저장·재접속 복구 |
| 배포 | Dockerfile만 존재 | PORT 대응·Render Blueprint·헬스체크 |

자동 선정은 규칙 기반입니다. 영상의 의미나 상품 정보를 이해하는 AI는 아니며, 가격·위치·사용 팁은 사용자가 사실에 맞게 입력합니다. 최대 18개를 업로드하며 최종 영상에는 최대 10장면이 들어갑니다. 소스 영상의 음성은 제거되며, 선택한 배경음악만 사용합니다.

## 사용법

1. Safari로 배포 URL을 엽니다.
2. 사진·영상 1~18개를 선택합니다. 음악 포함 총 400MB 이하입니다.
3. 주제와 자막을 적습니다. 한 줄당 자막 하나이며 비워 두면 기본 문구가 사용됩니다.
4. 기본 1080p로 제작합니다. 업로드가 끝날 때까지 Safari를 켜 두세요.
5. 미리보기를 보고 장면별 자막을 수정한 뒤 다시 만들 수 있습니다.
6. MP4 저장을 누릅니다. Safari 다운로드 파일을 열고 공유 → 비디오 저장을 사용할 수 있습니다.

작업 링크는 브라우저에 저장됩니다. 같은 브라우저로 다시 접속하면 마지막 작업 상태를 불러옵니다. 서버 재시작 시 진행 중인 렌더는 재시도해야 합니다. Render 기본 파일시스템은 재배포·재시작 시 사라질 수 있으므로 완성 파일은 바로 저장하세요. 작업 링크를 아는 사람은 영상을 볼 수 있으며, 정상 실행 중 약 24시간 후 서버에서 정리됩니다.

## 로컬 실행

Python 3.12, FFmpeg(libx264/libx265), Noto CJK 폰트가 필요합니다.

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app:app --host 0.0.0.0 --port 8000 --workers 1
```

## Render 배포

저장소 루트의 `render.yaml`을 Blueprint로 가져옵니다.

- Docker 서비스, Singapore 지역, `/healthz` 헬스체크입니다.
- Blueprint는 Starter 유료 인스턴스를 지정합니다. 실제 가격은 Render 생성 화면에서 확인하세요. 무료 인스턴스는 1080p 렌더의 메모리·시간 제약 때문에 권장하지 않습니다.
- 한 인스턴스·한 Uvicorn worker로 운영합니다. 대기열 기본 4개, 렌더 동시 실행 1개입니다.
- 프록시가 업로드 크기를 제한하면 400MB 미만이어도 실패할 수 있으므로 파일 수·크기를 줄여 주세요.
- 임시 파일 보존이 필요하면 Render disk를 별도로 연결하고 `JOBS_DIR`을 해당 경로로 지정하세요.
- 기본 구성에는 로그인이 없습니다. 개인용으로 사용하고 서비스 URL을 무분별하게 공유하지 마세요. 여러 사용자를 위한 서비스로 확대할 때는 인증·사용자별 할당량과 외부 작업 큐가 필요합니다.

## 검증

```sh
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

실제 FFmpeg로 HEIC와 HEVC MOV를 섞어 1080p 파일을 생성하고, 코덱·480프레임·20초·Range 재생·자막 재제작을 확인합니다. 별도 테스트에서는 18개 전체 분석과 상위 장면 선정을 확인합니다. 실제 iPhone 하드웨어와 HDR/Dolby Vision 원본 검증은 별도로 필요합니다.
